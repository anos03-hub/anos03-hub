# Hi, I'm Anastasios

I'm building practical projects in Data Science and Machine Learning, with a particular interest in football analytics, recommender systems, and applied AI.

## Current focus

- Python for data analysis
- Machine Learning
- Football analytics
- Recommendation systems
- Model evaluation and validation

## Featured projects

- **Undervalued Football Players**  
  Position-specific player valuation models using FBref and Transfermarkt data, with OOF validation, backtesting, and scouting shortlists.

- **Movie Recommender**  
  Recommendation system using collaborative filtering and PyTorch matrix factorization, deployed with Streamlit.

## Tech

Python · pandas · NumPy · scikit-learn · PyTorch · Streamlit · Git
